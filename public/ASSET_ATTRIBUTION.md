# Third-party asset attribution

The primary A320 visual is loaded from **amvlab/aircraft-models** when the browser can reach the asset URL. The A320 model is licensed under **Creative Commons Attribution 4.0 International (CC BY 4.0)**.

Source repository: https://github.com/amvlab/aircraft-models

The simulator keeps a procedural aircraft fallback so the flight experience remains usable if the external model cannot be downloaded.
